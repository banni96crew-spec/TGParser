Уточнение по исследованию: Directory queries лучше сделать более целевыми. Общие `ecommerce`, `стартапы`, `маркетплейсы` дают много новостей, курсов и подрядчиков.

Более качественные 10:

```text
чат предпринимателей
сообщество предпринимателей
владельцы бизнеса
предприниматели москва
предприниматели санкт-петербург
владельцы интернет-магазинов
чат селлеров
продавцы маркетплейсов
владельцы магазинов
основатели стартапов
```

Главный принцип: **роль клиента + тип сообщества + ниша/город**. Например:

```text
предприниматели казань
владельцы салонов красоты
владельцы клиник
селлеры ozon
фаундеры чат
```

Не используйте в Directory queries `разработка сайтов`, `веб-дизайн`, `создание сайтов` — они преимущественно находят конкурентов, а не заказчиков. Это подтверждает [исследование директорий](9b823dd0-06c4-4dfa-a855-1619dd6cff43).
